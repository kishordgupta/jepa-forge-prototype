# Official-model transfer protocol

This is a separate bounded transfer study, declared before vision test metrics are opened. It does not claim to reproduce the official I-JEPA or V-JEPA benchmarks, compare foundation-model pretraining compute, or establish performance on natural video.

The public image tasks are 600 label-independently sampled Digits images and 600 Semeion images (subset seed 9026). Original grayscale images are replicated into RGB and resized by the published I-JEPA processor. The official Meta `facebook/ijepa_vith14_1k` checkpoint is pinned to revision `f157467ea509bc356ff9f61fd3c0d840eec5e04e`, loaded without remote executable code through Transformers 4.57.6, frozen, and mean pooled over patch tokens. Its ImageNet-1K pretraining is external to this experiment. Writer identity is not supplied by these loaders, so these are row-held-out transfer checks.

The video task contains 240 generated clips: 60 simulated entities with four contiguous eight-frame clips each. Images are 16x16 grayscale Gaussian shapes with four motion laws: horizontal periodic wrap, vertical periodic wrap, circular motion, and horizontal sinusoidal motion. Entity-specific phase, speed, size and intensity are seeded. Whole entities are held out. This is a toy kinematic discrimination task, not a physical simulator or a natural-video benchmark. The custom pilot treats each frame as an ordered token with 256 pixel channels and uses its existing 1D convolutional encoder. The direct supervised baseline uses the same encoder with a supervised head.

The official V-JEPA ViT-L/16 target encoder uses the original VideoMix2M checkpoint from Meta and native source pinned to `51c59d518fc63c08464af6de585f78ac0c7ed4d5`. Its training configuration uses 16 frames; evaluation here passes eight frames using the official positional interpolation. Masked frames are replicated to RGB, resized bilinearly to 224x224 without cropping, and ImageNet normalized. We average all output spatiotemporal patch tokens. This deterministic resizing is an explicitly disclosed adapter. All weights remain frozen. Checkpoint/source hashes, parameter counts and actual input/output device/shape evidence are stored.

Four image half-masks or four half-frame masks use the existing schema templates. **Hidden source pixels are zeroed before resizing**, so interpolation cannot reveal them. Every model receives the same source-pixel observation set within a candidate. The pixel budget matches; architecture, interpolation and external pretraining compute do not. Fixed pretrained embeddings are cached without labels. Each split's probe selection is passed copies of only its train/validation embeddings and labels. A row can occur in different partitions across repeated splits, but no model is fitted across splits. No test label or metric enters any selection.

Three label-independent split seeds are 4026, 5026 and 6026; neural seed is 7. Scratch JEPA, direct supervision, raw linear, Extra Trees, and train-only filter/embedded selection controls are independently selected on these same subsets. Scratch models use the extension's 30-epoch configuration, with the same 120-epoch fixed-mask control. Official frozen embeddings use the same five-strength logistic probe grid. All nine task/split choices, including official probes and scratch models, are locked before scoring any vision test labels. No train+validation refit occurs.

Report all three split scores and their mean/sample standard deviation, including unfavorable outcomes. Official pretrained weights are not redistributed; the artifact provides download recipes and hashes. Both official weight families have noncommercial research license terms; dataset/generated-data licenses are recorded separately.

Primary sources: [I-JEPA](https://github.com/facebookresearch/ijepa), [official Meta I-JEPA checkpoint](https://huggingface.co/facebook/ijepa_vith14_1k), [V-JEPA](https://github.com/facebookresearch/jepa).
